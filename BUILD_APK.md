# Как получить APK без Android Studio на компьютере

1. Войдите на https://github.com/ и создайте новый пустой репозиторий (например, `SpanishVerbTrainerB2`).
2. Загрузите в репозиторий все файлы и папки из этого архива. В корне репозитория должны находиться `settings.gradle.kts`, `build.gradle.kts`, папка `app` и папка `.github`.
3. Откройте вкладку **Actions** репозитория.
4. Выберите workflow **Build Android APK** и нажмите **Run workflow**. Если workflow не отображается, сначала откройте `.github/workflows/build-apk.yml` в репозитории и убедитесь, что файл загружен в ветку `main`.
5. Дождитесь зелёного статуса завершения сборки.
6. Откройте завершённый запуск workflow. Внизу страницы в разделе **Artifacts** скачайте `SpanishVerbTrainerB2-debug-apk`.
7. Распакуйте скачанный ZIP. Внутри будет `app-debug.apk`. Перешлите APK на Android-телефон и откройте его. Android может попросить разрешить установку приложений из этого источника.

Это debug APK для тестирования, не опубликованный релиз Google Play.
